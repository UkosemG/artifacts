# Artifacts

The public dashboard: a plain static page listing only the artifacts that have been
explicitly published from the private admin dashboard.

This repo's content is generated and pushed automatically by the `admin/` app in the
[evelabs-first](https://github.com/UkosemG/evelabs-first) repo whenever changes are
published — don't edit `artifacts.json` here by hand, it will be overwritten on the next
publish.

Hosted with GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
